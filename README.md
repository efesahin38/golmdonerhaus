# Golm Döner Haus Website

Responsive landing page for Golm Döner Haus in Potsdam-Golm.

## Lokal starten

```bash
cd /Users/efesahin/Desktop/golm
python3 -m http.server 8080
```

Dann im Browser: [http://localhost:8080](http://localhost:8080)

GitHub Pages: `https://efesahin38.github.io/golmdonerhaus/`

## Inhalt

- Hero mit Food-Truck-Bild
- Vollständige Speisekarte (Preise von Lieferando)
- Über-uns-Bereich
- Kontakt mit Karte, Adresse und Öffnungszeiten
- Alle „Online Bestellen“-Buttons → [Lieferando](https://www.lieferando.de/speisekarte/golm-dner-haus?shipping=pickup)

## Struktur

- `index.html` — Hauptseite (Startseite)
- `css/style.css` — Styles
- `js/menu.js` — Menüdaten
- `js/main.js` — Navigation & Rendering
- `images/` — Logo, Hero, Menü- und Über-uns-Bilder
